# 01. 요구사항

## 기능

| 구분 | 기능 | 누가 |
|---|---|---|
| 회원 | 가입(아이디, 비밀번호, 표시 이름) | 누구나 |
| 회원 | 내 정보 조회 | 로그인한 사용자 |
| 글 | 목록 조회, 검색(키워드, 작성자, 태그), 페이징 | 누구나 |
| 글 | 상세 조회 | 누구나 |
| 글 | 등록 | 로그인한 사용자 |
| 글 | 수정, 삭제 | 작성자 또는 관리자 |
| 관리 | 작성자별 글 수 통계 | 관리자 |

## 비기능

| 항목 | 기준 |
|---|---|
| 인증 | HTTP Basic, 세션 없음. 비밀번호는 bcrypt 해시로 저장 |
| 오류 응답 | 모든 오류는 `code`, `message`, `issues` 형식 |
| 데이터베이스 | 기본 H2, `oracle` 프로파일에서 Oracle(JSON 컬럼) |
| 화면 | 서버 렌더링(Thymeleaf) 읽기 화면, React 작성 화면, Swagger 문서 |
| 품질 | 계층·모듈 경계를 테스트로 고정, CI에서 H2와 Oracle 모두 실행 |

## 범위 밖

파일 첨부, 댓글, 이메일 인증, 비밀번호 찾기, 소셜 로그인, 글 임시 저장.
