# ch01. Hello Spring Boot

## 학습 목표

- Spring Framework와 Spring Boot의 역할 차이를 설명한다.
- Gradle 기반 Spring Boot 프로젝트의 디렉터리 구조를 읽는다.
- 애플리케이션을 실행하고 `GET` 요청으로 응답을 확인한다.
- MockMvc로 컨트롤러를 테스트한다.

## 선수학습

Java 기본 문법 (클래스, 메서드, record)

## 범위

| 항목 | 내용 |
|---|---|
| 예제 | [`examples/ch01-hello-spring`](../../../examples/ch01-hello-spring) |
| API | `GET /hello`, `GET /info` |
| 테스트 | `@SpringBootTest` + MockMvc 4건 |
| 다루지 않는 것 | Profile과 외부 설정(ch02), DI와 Bean(ch03), CRUD(ch05) |
